# Sobre o Crawler

## Tecnologia
O atual crawler utiliza como tecnologia principal javascript. \
A motivação da troca de linguagem decorre do fato da migração do banco de dados para nuvem, sendo o ambiente no qual o crawler executa baseado em NodeJS.\
Sendo assim, a única motivação de mudança foi a simplicidade de implementação do projeto com o menor gasto possível.

## Funcionamento
O crawler executa todos os dias às 9h da manhã, horário de Brasília.\
Caso note-se que os dados do dia não foram atualizados, pode ser entrado em contato diretamente com o mantenedor principal do repositório: @PGuardini.
